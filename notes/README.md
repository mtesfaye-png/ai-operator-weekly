# Mohil's takes

Drop a file named after the issue date (for example `2026-10-25.md`) before the Saturday run, with a line per
story or topic. The writer uses these for every "Mohil take". With Airtable, you can paste the same text into the
`mohil_notes` field of that week's Issues row instead.

Without notes, each take is written as `[DRAFT TAKE - Mohil to confirm]` and the gate flags it as a warning.
